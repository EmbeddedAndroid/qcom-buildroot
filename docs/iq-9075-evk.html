IQ-9075 Evaluation Kit

Qualcomm IQ-9075 EVK

The IQ-9075 Evaluation Kit is built around the Qualcomm Lemans SoC (SA8775P / QCS9075) and boots from UFS. lemans.mk builds its open boot chain and a Buildroot distribution; the quick start walks through it and the focused and comprehensive decks go into depth.

ConsolettyMSM0, 115200 8N1

Boot chain

XBL -> U-Boot SPL (tz) -> BL31 -> OP-TEE -> U-Boot proper -> systemd-boot -> UKI

U-Boot SPL replaces TF-A BL2 as the first open-source stage; it is linked at 0x1c100000. It reads the FIT image in the uefi partition, loads BL31 at 0x1c200000, OP-TEE at 0x1c300000 and U-Boot proper at 0xaf000000, and jumps to BL31, which starts OP-TEE and then U-Boot proper.

Build

make toolchains
make all          # components and efi.bin
make bootimage    # tz.mbn + uefi.elf

See the quick start for iterating on one component and for the stock Yocto BSP flows.

Flash

The board has to be in EDL mode on the build host; Qualcomm's Flash over QLI guide describes how, and how to install qdl. 

make fetch-blobs    # stock boot binaries, CDT and partition tables
make flash-loader   # LUNs 1 to 5: boot chain, tz.mbn and uefi.elf from the build
make flash-kernel   # LUN 0: efi.bin

flash-loader also writes the QUP firmware (qupv3fw.elf) into the qupfw partitions, which U-Boot needs for the GENI serial engines. Recovery (flash-ufs-provision), the SAIL NOR image (flash-sail) and packages for flashing from Windows (edl-package, edl-bootloader) are described in the quick start, the comprehensive deck and make help.

On the board

The rootfs carries xtest and qcom-tests, which runs the ADSP and CDSP FastRPC tests (the DSPs are started through the OP-TEE PAS service), a video encode and decode round trip and a CPU stress test.
